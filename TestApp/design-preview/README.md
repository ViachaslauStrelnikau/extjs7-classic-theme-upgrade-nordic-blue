# Nordic Soft: сравнение дизайна (TASK-022)

Открыть http://127.0.0.1:51754/design-preview/index.html через существующий `TestApp/modern-preview/serve.cjs`.

Обе стороны загружают одну реальную testing-сборку Nordic Soft из build/theme-soft/testing, SDK 7.7.0.31 и один sample.js. Слева нет дополнительного CSS, справа подключается только reference.css. Motion общий, по умолчанию выключен. Основная кнопка назначается явно demo-primary на обеих сторонах. Класс не влияет на левую сторону.

Это демонстрационный слой для визуального выбора, не новая Cmd-сборка пакета и не приёмка совместимости. Он не меняет пакеты, приложение, SDK, утверждённые изображения, политики или goldens. После согласования нужен отдельный этап переноса в Sass с проверкой реально используемых hooks и полной регрессией. Существующий release не включает эти файлы.

Источник направления: пользовательский прототип Google AI Studio https://aistudio.google.com/apps/6e40bd91-a982-4e6f-96dc-04692c369fa5?showPreview=true&showAssistant=true . Использованы наблюдаемые принципы иерархии поверхностей, лёгких кнопок, акцентов и разделителей. Код, шрифты, компоновка и данные React-прототипа не копировались.

Новых значков нет. Метрики не объявляются подтверждёнными только по CSS: фактическое сравнение демонстрации записывается в отчёте TASK-022. Прототип не заменяет Classic regression gates.
