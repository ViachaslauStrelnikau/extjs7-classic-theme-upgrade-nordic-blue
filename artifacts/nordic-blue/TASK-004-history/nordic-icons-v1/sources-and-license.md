# Источники и права

- Nordic SVG artwork создан для этого проекта заново программными векторными контурами. Внешние icon packs, шрифты и stock assets не использованы. Редактируемые SVG и генератор включены.
- Авторство в проекте: Nordic Blue project / generated with Codex. Отдельная лицензия на выпуск нового artwork пока не назначена владельцем проекта; это не импорт внешнего набора под неизвестной лицензией.
- Classic изображения используются как локальная сравнительная база из установленного Ext JS 7.7.0.31; исходные paths/hashes записаны в manifest. На SDK, Classic reference screenshots и исходные ресурсы распространяются условия Sencha/Ext JS; новая лицензия им не присваивается. Не включать сравнительные Classic assets в публичную поставку без проверки прав владельцем проекта.
- Локальный дизайн пользователя: docs/reference/nordic-blue. Его размеры не использованы как геометрический эталон.
- Ссылка 7.9 — только визуальный референс: https://examples.sencha.com/extjs/7.9.0/examples/classic/themes/
