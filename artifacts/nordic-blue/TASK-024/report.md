# TASK-024: оформление нового варианта исчезало

2026-10-25. DONE: исправление предпросмотра, не выпуск пакета темы.

## Воспроизведение

Пользователь показал, что оба варианта одинаковы после первоначального различия. В его открытой вкладке до исправления reference.css был загружен, но body.design-reference отсутствовал, а фон основной кнопки был transparent. Это воспроизведение дефекта, не субъективная слабая заметность дизайна. before.png сохраняет состояние до перезагрузки исправления.

## Причина и исправление

Прямые classList.add/toggle на body конфликтовали с кэшем классов Ext.dom.Element. Установленная SDK packages/core/src/dom/Element.js содержит classMap/classList и запись полного dom.className. Поэтому перенос classList.toggle в Ext.onReady (TASK-022) не решал дальнейшую потерю класса.

Идентичность демонстрации перенесена в собственный html[data-nordic-preview="reference"]. boot.js устанавливает этот атрибут после валидации variant до загрузки SDK. reference.css использует атрибут вместо body.design-reference. Из boot.js и sample.js удалены обе записи design-reference в body. Ext-классы не переопределяются. Никаких observers, интервалов, постоянного восстановления className или SDK overrides.

## Фактическая проверка исправления

paint-checks.json фиксирует5контрольных точек: после reload; мышь/вкладка/Tab; окно/возврат фокуса; перезагрузка при motion on; перезагрузка при motion off. Во всех точках правая колонка сохраняет reference attribute и реально отличается по вычисленным фонам основной кнопки, заголовка и текстового поля; также записан акцент вкладки. Правый заголовок белый против rgb(232,239,248), кнопка rgb(50,117,214) против transparent, поле без text-bg.gif, вкладка с синим underline. Это проверка paint persistence, не только наличия загруженного CSS.

После финальной перезагрузки253пары видимых элементов совпали по записанным rect/font/padding/margin/border-width; сырые данные metrics.json. after.png снят после проверок. Ограниченный охват: браузер приложения, normal geometry; не полная Classic/DPR/browser матрица, не новая Cmd-сборка. Переключение motion проверялось как повторная загрузка и сохранение оформления, не приёмка самой motion API.

## Исправление предыдущего вывода

Числа равных метрик TASK-022/023 сами по себе не подтверждали устойчивое применение нового paint. Предыдущие снимки показывали кратковременное оформление, но недостаточно проверяли его сохранение. Исторические artifacts не перезаписывались; для устойчивого варианта использовать доказательства TASK-024. Это не означает, что старая равная геометрия доказывала различие тем.

Действующие пакеты, SDK, compiled output, оригинальное приложение, иконки, политики и goldens не изменены. Исправлен только отдельный design-preview. Обновлённая вкладка оставлена открытой: http://127.0.0.1:51754/design-preview/index.html . Конкретное оформление по-прежнему ожидает отзыва пользователя; production adoption не подразумевается.
