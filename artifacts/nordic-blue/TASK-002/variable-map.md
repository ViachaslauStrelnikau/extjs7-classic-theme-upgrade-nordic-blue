Проверено 300 SCSS-файлов цепочки theme-base → theme-neutral → theme-classic. Найдено 2077 имён глобальных объявлений на уровне начала строки. Полная цепочка объявлений, зависимости, производные переменные и места использования — в variable-map.json. Source-index сохраняет все найденные обращения; статический индекс не заменяет Sass compiler и будущие geometry checks.

## Нельзя считать цветовой переменной

- Tree glyph-color hooks существуют, но при `$enable-font-icons=false` штатные стрелки/folders/leaf используют resources. Их artwork обновляется задачами 003/004/013, а не включением font icons. Row/selection backgrounds Tree приходят из view/Table.scss.
- Slider color hooks находятся под `@if $slider-imageless`; `$slider-imageless=dynamic($enable-font-icons)` и Classic наследует false. Не включать imageless ради палитры: slider backgrounds/thumbs — изображения, их размеры/offsets сохраняются.
- Gradients, opacity, glyphs, images и inclusion flags не входят в цветовой allowlist автоматически. См. variable-policy.json и sdk-audit.md.
