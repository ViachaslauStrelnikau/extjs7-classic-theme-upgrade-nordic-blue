# TASK-023: выразительный вариант предпросмотра v2

2026-10-25. DONE для ревизии демонстрации, не интеграция темы.

Пользователь сообщил, что разница в TASK-022 почти незаметна, и разрешил более выразительный вариант. Обновлены только TestApp/design-preview/reference.css и подписи index.html. Слева по-прежнему собранный Nordic Soft, справа CSS-кандидат v2. Общий sample.js не изменён.

## Изменения

- Белые заголовки вместо голубой заливки, синий акцент внутри прежней рамки.
- Белые панели инструментов; явно назначенная основная кнопка и нейтральные обычные.
- Плоские поля: снята декоративная background texture text-bg.gif; отдельные invalid-field классы исключены из этого правила. Обработка всех invalid-сочетаний требует отдельной приёмки при переносе.
- Нейтральный светло-серый заголовок таблицы, менее заметные вертикальные разделители и чередование строк.
- Выбранная строка/узел с голубой заливкой и синим внутренним акцентом, совместимый paint клавиатурного фокуса.
- Неактивные вкладки без отдельных видимых рамок, активная с синим подчёркиванием; размеры и скругления не менялись.
- Более выраженная тень окна в том же opt-in demo.
